# 快速上手

这份说明带你把 MyBrowser 的主要功能走一遍。完整说明见 [README](../README.md)，全部快捷键见 [键盘快捷键](KEYBOARD_SHORTCUTS.md)。

## 运行

```bash
pnpm install   # 第一次运行前安装依赖（需要 Node.js 18+）
pnpm dev       # 开发模式
pnpm start     # 生产模式
```

## 1. 浏览

- 地址栏输入 `github.com` 回车，会自动补上 `https://`；输入普通文字则用必应搜索
- 默认主页和新标签页是必应（`https://cn.bing.com`）
- 工具栏的后退、前进、刷新、主页按钮，和其他浏览器一样

## 2. 标签页

- 点 **+** 或按 **Ctrl+T** 新建标签页，点 **×** 或按 **Ctrl+W** 关闭
- 至少保留一个标签页，最后一个关不掉
- 每个标签页的强调色取自所访问网站，方便一眼认出

## 3. 两种布局

- **经典布局**：标签栏在窗口顶部
- **侧栏布局**：标签页和收藏夹竖排在左侧，可以收起成只显示图标的窄条

在设置页的“外观”里切换。切换时已打开的页面不会刷新。

## 4. 书签

- 点地址栏右端的星标或按 **Ctrl+D** 收藏，再点一次取消
- 经典布局点工具栏的收藏夹按钮打开收藏夹；侧栏布局的收藏夹一直显示在侧栏里
- 书签保存在用户数据目录的 `bookmarks.json`（Windows 下通常是 `%APPDATA%\MyBrowser`）

## 5. 菜单与设置页

- 点菜单按钮（经典布局在工具栏右端，侧栏布局在侧栏底部）：主题快速切换、新建标签页、收藏夹、开发者工具、重新加载、强制刷新、更多设置、关于
- **更多设置** 或 **Ctrl+,** 打开设置页（地址栏显示 `mybrowser://settings`），左侧四个分区：
  - **外观**：布局、主题（浅色 / 暗黑 / 跟随系统）、侧栏收起
  - **网页**：允许跨域。只对之后新开的标签页生效，地址栏左端的标记显示当前标签页的实际状态
  - **AI 接口（MCP）**：见下一节
  - **关于 MyBrowser**：版本、项目主页、问题反馈
- 设置页顶部可以搜索设置项；所有设置下次启动时保持不变

## 6. 让 AI 操作浏览器（MCP）

> ⚠️ 开启后，连接的 AI 可以列出、读取和操作**所有**已打开的标签页，包括你已经登录的页面。只连接你信任的客户端，不要把令牌发给别人。

1. 按 **Ctrl+,** 打开设置页，进入“AI 接口（MCP）”，打开“允许 AI 客户端连接”
2. 点“连接配置”，选你的客户端（Claude Code、Cursor、VS Code、Claude 桌面版或其他），复制现成的配置
3. 在客户端里粘贴配置，然后让 AI 打开网页、读取内容、点击或填写表单试试

AI 打开的标签页默认在后台，标题旁有 AI 标记，不会抢你的焦点。15 个工具、限制和故障排查见 README 的“AI 接口（MCP）”一节。

## 7. 调试

- **F12** 打开或关闭当前网页的开发者工具
- **Ctrl+Shift+R** 或 **Ctrl+F5** 强制刷新（忽略缓存）

## 遇到问题

1. 确认 Node.js 是 18 或更高版本
2. 重新安装依赖：`pnpm install`
3. 还不行就删掉 `node_modules` 后重新安装
4. AI 接口相关的问题，先看 README 里的“故障排查”表
