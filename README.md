# My Browser

基于 Electron 开发的现代浏览器应用

## 功能特性

- ✅ **跨域开关** - 默认放行跨域请求，可在设置面板里关闭
- ✅ **多标签页功能** - 支持打开多个网页标签，显示站点图标和加载状态
- ✅ **导航功能** - 前进、后退、刷新、主页按钮
- ✅ **书签管理** - 添加、查看、删除收藏的网页
- ✅ **智能地址栏** - 支持网址输入和搜索功能
- ✅ **两种布局** - 经典（标签栏在上）和侧栏（标签页、收藏夹竖排在左），可随时切换
- ✅ **浅色 / 暗黑主题** - 默认跟随系统，可手动切换
- ✅ **快捷键支持** - 丰富的键盘快捷键操作
- ✅ **AI 接口（MCP）** - 可选开启，让 Claude Code、Cursor 等 AI 工具通过浏览器打开、读取和操作网页

## 快速开始

### 安装依赖

使用 pnpm 安装项目依赖：

```bash
pnpm install
```

### 运行应用

开发模式运行：

```bash
pnpm dev
```

生产模式运行：

```bash
pnpm start
```

### 构建应用

打包应用：

```bash
pnpm build
```

## 使用说明

### 基本操作

1. **导航**：使用前进、后退、刷新、主页按钮进行页面导航
2. **地址栏**：输入网址或搜索关键词，按回车键
3. **标签页**：点击 "+" 按钮新建标签页，点击 "×" 关闭标签页
4. **书签**：点击地址栏右端的星标，把当前页面加入收藏夹

### 菜单与设置页

点击菜单按钮打开菜单（经典布局在工具栏右端，侧栏布局在侧栏底部）：主题快速切换（浅色 / 暗黑 / 跟随系统）、
新建标签页、收藏夹、开发者工具、重新加载、强制刷新，以及“更多设置”和“关于”。AI 接口开启时，菜单顶部会显示它的运行状态。

“更多设置”（**Ctrl+,**）在一个标签页里打开设置页，地址栏显示 `mybrowser://settings`。左侧是分区，顶部可以搜索设置项：

- **外观**
  - **布局**：经典 / 侧栏。切换时已打开的页面不会刷新；侧栏可以收起成只显示图标的窄条
  - **主题**：浅色 / 暗黑 / 跟随系统
- **网页**
  - **允许跨域**：打开后，新开的标签页不受同源策略限制，方便调试接口；关闭后，新开的标签页和普通浏览器一样。
    这个开关只对之后新开的标签页生效，已经打开的标签页保持原状。地址栏左端的标记显示当前标签页的实际状态
    （“跨域已放行”或“未放行跨域”）
- **AI 接口（MCP）**：开关、服务状态、监听地址、连接配置和配置文件位置，见下一节
- **关于 MyBrowser**：版本、项目主页、问题反馈

布局、主题、跨域开关、AI 接口开关和侧栏的收起状态都会记住，下次启动时保持不变。

### AI 接口（MCP）

> ⚠️ **开启后，连接的 AI 可以列出、读取和操作所有已打开的标签页**，包括你自己打开、已经登录的页面，
> 并能在页面里执行 JavaScript、填写和提交表单。只连接你信任的客户端，不要把访问令牌发给别人。
> 设置页本身不会出现在 AI 的标签页列表里，AI 无法修改浏览器设置。

在设置页的“AI 接口（MCP）”分区打开“允许 AI 客户端连接”，浏览器会在 `http://127.0.0.1:17345/mcp` 启动 MCP 服务。
服务只监听本机，每个请求都要带 `Authorization: Bearer <令牌>`，网页里发起的请求一律拒绝。

点“连接配置”可以看到各客户端现成的配置（已填好地址和令牌，令牌默认打码）：

- **Claude Code**：一条 `claude mcp add --transport http ...` 命令
- **Cursor**：`mcpServers` 格式的 JSON
- **VS Code**：`servers` 格式的 JSON（`type: "http"`）
- **Claude 桌面版**：只支持 stdio，通过随应用附带的转接脚本 `stdio-bridge.js` 连接，配置里不含令牌
- **其他客户端**：单独的地址和令牌

端口和令牌保存在用户数据目录的 `mcp.json`（设置页里显示完整路径，可以直接打开所在文件夹）。
要换端口，关闭 AI 接口后修改 `port`（1024–65535），再重新打开；删除 `token` 字段会在下次开启时生成新令牌，
之前配置过的客户端需要更新。端口被占用时设置页会显示原因，修好后点“重试”即可。

**Claude 桌面版与便携版**：安装版的配置直接用 MyBrowser 自己的程序运行转接脚本（`ELECTRON_RUN_AS_NODE=1`），不需要另装 Node.js。
便携版每次运行时会解压到临时目录，Claude 没法用它启动脚本，所以便携版生成的配置会把脚本复制到用户数据目录的
`mcp-bridge/` 下，改用本机的 `node`（18 或更高版本）运行；没有 Node.js 的话请用安装版。转接脚本不会替你启动浏览器。

#### 工具与限制

共 15 个工具：`list_tabs`、`open_tab`、`close_tab`、`activate_tab`、`navigate`、`navigate_history`、`get_html`、`get_text`、
`query_dom`、`screenshot`、`click`、`fill`、`dispatch_event`、`wait_for`、`evaluate`。

- AI 打开的标签页默认在后台，标题旁有 AI 标记；操作后台标签页不会把它切到前台，也不会抢走你正在用的输入框的焦点。
- `click` 默认发送真实鼠标事件（页面看到 `isTrusted: true`），被遮挡、不可见或禁用的元素会返回 `element_not_interactable`。
- **`dispatch_event` 发出的是合成事件**（`isTrusted: false`）。很多需要用户手势的行为不会发生：打开文件选择框、全屏、
  弹出窗口、复制到剪贴板、播放有声视频等；合成的键盘事件也不会往输入框里打字（填写请用 `fill`）。部分网站会识别并忽略合成事件。
- `fill` 支持文本框、下拉框、勾选框和单选框，不支持文件选择框；提交表单会走浏览器的校验。
- 选择器只查主文档，不进 iframe 和 Shadow DOM；截图只截可见区域或某个元素，不支持整页长截图。
- 超时返回不会撤销已经发生的点击或提交，也不会停止页面里还在跑的脚本。

#### 故障排查

| 现象 | 原因和处理 |
| --- | --- |
| 设置页显示“启动失败：端口被占用” | 可能已有另一个 MyBrowser 开着 AI 接口。关掉它，或在 `mcp.json` 里换个端口，再点“重试” |
| 客户端报 401 / 令牌不匹配 | 令牌换过了。重新打开“连接配置”复制新配置 |
| 客户端连不上 / 转接脚本说“连不上 MyBrowser” | MyBrowser 没开，或 AI 接口没开启；端口改过时客户端配置里的地址也要改 |
| 返回 403 | 请求带了 `Origin` 头（浏览器网页发起的）或 `Host` 不是本机地址，这是有意拒绝的 |
| 工具返回 `tab_busy` | 这个页面里上一段脚本还没跑完（例如死循环）。等它结束、刷新页面或关掉标签页 |
| 工具返回 `window_minimized` 或 `render_unavailable` | 需要布局的操作（截图、真实点击等）在窗口最小化或不能渲染时做不了，把窗口还原后重试 |
| 标签页编号突然无效（`tab_not_found`） | 标签页被关了，或浏览器界面重新加载过。重新 `list_tabs` |
| Claude 桌面版里看不到 mybrowser | 保存配置后要完全退出 Claude 再打开；便携版还要确认本机能运行 `node` |

### 书签管理

- 点击地址栏右端的星标，收藏或取消收藏当前页面
- 经典布局：点击工具栏的收藏夹按钮，从右侧展开收藏夹；侧栏布局：收藏夹一直显示在侧栏里
- 在收藏夹里点击条目可直接访问
- 鼠标移到条目上，点击右侧的 "×" 可移除

### 搜索功能

地址栏支持智能识别：
- 完整网址（如：https://www.example.com）
- 域名（如：example.com）
- 搜索关键词（将自动使用百度搜索）

### 快捷键操作

#### 开发调试
- **F12** - 打开/关闭开发者工具

#### 页面操作
- **Ctrl+R** 或 **F5** - 刷新页面
- **Ctrl+Shift+R** 或 **Ctrl+F5** - 强制刷新（清除缓存）

#### 标签页管理
- **Ctrl+T** - 新建标签页
- **Ctrl+W** - 关闭当前标签页

#### 导航操作
- **Alt+←** - 后退
- **Alt+→** - 前进
- **Ctrl+L** - 聚焦地址栏

#### 书签管理
- **Ctrl+D** - 添加当前页面到书签

#### 设置
- **Ctrl+,** - 打开设置页
